# C&M Busan 2026

2026/09/14–09/20 釜山旅行用的手機 PWA。

功能：
- 每日行程＋Naver Map / Google Maps 快捷導航
- 航班、住宿、出發前 checklist
- Open-Meteo 即時 7 日天氣
- C / M 共同 KRW 記帳與分帳
- 手機端「想去」清單，可旅途中直接新增
- PWA：可加到 iPhone / Android 主畫面
- 無 npm、無 build，直接用 GitHub Pages 部署

詳細步驟請看：`手機安裝與GitHub操作.md`
